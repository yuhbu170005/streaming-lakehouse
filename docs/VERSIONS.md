# Version and compatibility matrix

Reviewed on 2026-11-08. Phase 0 verifies upstream support and artifact availability for the engine matrix. Runtime integration is verified when the corresponding services are added.

| Component | Phase 0 baseline | Compatibility evidence |
|---|---|---|
| Python | 3.12.16 | Exact development and CI interpreter in `.python-version`. |
| uv | 0.13.6 in CI | CI and local Make targets use `uv.lock` with `--locked`. uv 0.13.6 is the first checked release with a managed CPython 3.12.16 Linux x86_64 build. The initial local foundation run used uv 0.13.7. [uv releases](https://github.com/astral-sh/uv/releases) |
| Ruff, pytest, pre-commit | 0.17.2, 9.1.1, 4.7.0 | Development dependencies pinned in `pyproject.toml` and resolved in `uv.lock`. |

Spark 4.1.4 was within the two-week settling window. The Spark 4.1.3 Docker tag lists arm64 and amd64. [Spark releases](https://spark.apache.org/documentation) · [Spark 4.1.3 requirements](https://spark.apache.org/docs/4.1.3/) · [Iceberg engine matrix](https://iceberg.apache.org/multi-engine-support/) |
| Spark Kafka connector | `org.apache.spark:spark-sql-kafka-0-10_2.13:4.1.3` | Matches Spark and Scala. The connector POM declares `kafka-clients:3.9.1`. Redpanda implements the Kafka protocol. Verify idempotent writes and Spark reads against the pinned broker during ingest and Bronze work. ## Binance source contract

The official Spot docs list the public market-data WebSocket base, combined-stream envelopes, a maximum of 1,024 streams per connection, and a limit of five client control messages per second. They document the 24-hour connection lifetime and the `serverShutdown` event. REST `GET /api/v3/aggTrades` on the market-data host accepts an inclusive `fromId`. Phase 1 validates reconnect and gap assumptions against fixtures and the live source. [WebSocket streams](https://github.com/binance/binance-spot-api-docs/blob/master/web-socket-streams.md) · [REST API](https://github.com/binance/binance-spot-api-docs/blob/master/rest-api.md#compressedaggregate-trades-list)
